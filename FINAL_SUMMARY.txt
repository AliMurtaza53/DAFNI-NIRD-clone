## Troubleshooting for Your Advisor

### Common Issues & Solutions

**Issue**: "Data files not found"
**Solution**: 
- Check `data/README.md` (Step 4: Verify Data)
- Ensure directory structure matches exactly:
  ```
  data/
  ├── study_area/
  ├── networks/faf5/
  └── od_data/
  ```

**Issue**: "ModuleNotFoundError: nird"
**Solution**: 
```bash
micromamba activate nird
python -c "import nird; print(nird.__file__)"
```

**Issue**: Memory errors running scripts
**Solution**: 
- Reduce dataset size (clip to smaller region)
- Increase system RAM if possible
- Run scripts individually (not in parallel)

**Issue**: Config paths don't match
**Solution**: 
- Edit `config.json` with local paths
- Example: `"faf5_network_path": "path/to/data/networks/faf5/faf5_road_links.gpq"`
